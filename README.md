# WAN Network Design

## Overview
This project covers the design and configuration of a Wide Area Network (WAN), including Variable Length Subnet Masking (VLSM) subnetting calculations and a complete network topology export. The design demonstrates efficient IP address allocation and WAN connectivity planning for a multi-site organisation.

## Project Files

| File | Description |
|---|---|
| `VSLM.xlsx` | VLSM subnetting calculations and IP address allocation scheme |
| `_Exports_unetlab_export-20251026-215903 (1).zip` | Network topology export from UNetLab/EVE-NG simulation environment |

## Key Concepts
- **VLSM (Variable Length Subnet Masking)** — efficient IP address allocation across multiple network segments
- **WAN Topology Design** — hub-and-spoke and point-to-point link planning
- **UNetLab/EVE-NG Simulation** — network lab emulation and topology configuration
- **IP Addressing Scheme** — structured addressing plan for scalability

## Tools Used
- UNetLab / EVE-NG (network emulation)
- Microsoft Excel (IP address planning)
